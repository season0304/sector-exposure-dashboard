# 유럽 인프라 펀드 익스포저 대시보드

[대시보드 열기](https://season0304.github.io/sector-exposure-dashboard/)

100개 보유 펀드와 4개 후보 펀드를 분석하는 대시보드입니다. 보유 포트폴리오와 후보 펀드의 수치는 가상 데이터이며 실제 국민연금 운용자료가 아닙니다.

생키 샘플의 Adamo 조달·사용 예시는 별도로 제공된 Ardian·Adamo 문서의 금액을 사용합니다.

섹터별·국가별·펀드별 분석, 신규 펀드 투자 시뮬레이션, CSV 다운로드를 제공합니다. 이 저장소는 검증된 정적 빌드 전체를 보관하며 GitHub Pages에서 main 브랜치의 루트를 제공합니다.
